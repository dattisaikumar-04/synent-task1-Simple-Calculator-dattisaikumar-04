# 🧮 Simple Calculator (CLI)

A simple **Command-Line Calculator** built to perform basic arithmetic operations. This project is designed for beginners to understand user input, conditional statements, functions, and error handling.

## 📌 Objective

Build a command-line calculator that performs basic mathematical operations through user input.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* ⌨️ Takes input from the user
* ⚠️ Handles invalid inputs
* 🚫 Prevents division by zero
* 💻 Runs directly in the command line/terminal

## 🛠️ Operations

| Operation      | Description                                |
| -------------- | ------------------------------------------ |
| Addition       | Adds two numbers                           |
| Subtraction    | Subtracts the second number from the first |
| Multiplication | Multiplies two numbers                     |
| Division       | Divides the first number by the second     |

## ▶️ How to Run

1. Clone the repository:

```bash
git clone <your-repository-url>
```

2. Open the project folder:

```bash
cd simple-calculator
```

3. Run the program:

```bash
python calculator.py
```
 💡 Example

```text
Simple Calculator

Enter first number: 10
Enter second number: 5

Choose operation:
1. Addition
2. Subtraction
3. Multiplication
4. Division

Enter your choice: 1

Result: 15
```

## ⚠️ Error Handling

The calculator handles common invalid inputs such as:

* Entering letters instead of numbers
* Selecting an invalid operation
* Attempting to divide by zero


```
